# apps/web (reserved)

This is the future home of the **fresh** Wearhouse frontend. It will use the supplied Wearhouse logos (`Assets/`) and the Steam references (`Reference/`).

It is intentionally empty in the foundation change:

- no screens, components or build;
- no copy of the legacy renderer (`legacy/web/src/app.js`);
- when it exists, it will import API types only from `packages/contracts`.

Frontend work starts with its own OpenSpec change, after the foundation stop gate in `docs/architecture/foundation-readiness.md`.
